## Requirements

### Requirement: Shell parser does not panic on arbitrary input
`parser::parse()` SHALL NOT panic when given any arbitrary string input.

#### Scenario: Random bytes
- **WHEN** `parse()` is called with arbitrary byte sequences (valid UTF-8)
- **THEN** it SHALL return a result without panicking

### Requirement: Config parsers do not panic on generated CST
The config parsers (effect, predicate, command, rule) SHALL NOT panic when given CST nodes generated by existing test generators.

#### Scenario: Effect parser roundtrip
- **WHEN** `parse_effect` is called on a CST generated by `any_canonical_effect_cst`
- **THEN** it SHALL return Ok or Err without panicking

#### Scenario: Predicate parser roundtrip
- **WHEN** `parse_predicate` is called on a generated predicate CST
- **THEN** it SHALL return Ok or Err without panicking

#### Scenario: Command parser roundtrip
- **WHEN** `parse_command_pattern` is called on a generated command CST
- **THEN** it SHALL return Ok or Err without panicking

#### Scenario: Rule parser roundtrip
- **WHEN** `parse_rule` is called on a generated rule CST
- **THEN** it SHALL return Ok or Err without panicking

### Requirement: Migration preserves semantics with defines
Migration SHALL preserve evaluation semantics for configs that include `define` predicates.

#### Scenario: Config with defines evaluates identically after migration
- **WHEN** a generated config with defines is migrated
- **THEN** evaluating any command against original and migrated configs SHALL produce the same decision

### Requirement: validate_and_resolve does not panic
`validate_and_resolve()` SHALL NOT panic on arbitrary (rules, defines) input.

#### Scenario: Arbitrary rules and defines
- **WHEN** `validate_and_resolve` is called with generated rules and defines
- **THEN** it SHALL return Ok or Err without panicking

### Requirement: Doc functor laws hold
`Doc::map` SHALL satisfy the functor identity and composition laws.

#### Scenario: Identity law
- **WHEN** calling `doc.map(|x| x)` on an arbitrary Doc
- **THEN** the result SHALL be structurally equal to the original

#### Scenario: Composition law
- **WHEN** calling `doc.map(f).map(g)` vs `doc.map(|x| g(f(x)))`
- **THEN** the results SHALL be structurally equal

### Requirement: Pretty-printer idempotency
Pretty-printing a doc, parsing it back, and pretty-printing again SHALL produce the same output.

#### Scenario: Idempotent pretty-print
- **WHEN** `pretty(parse(pretty(doc, w)), w)` is computed
- **THEN** it SHALL equal `pretty(doc, w)`

### Requirement: Pretty-printer width monotonicity
Narrower widths SHALL produce at least as many lines as wider widths.

#### Scenario: Narrower produces more lines
- **WHEN** comparing `pretty(doc, w1)` and `pretty(doc, w2)` where `w1 < w2`
- **THEN** the line count of the w1 output SHALL be >= the line count of the w2 output

### Requirement: Shell segment inverse
Concatenating all segments of a parsed shell string SHALL reproduce the original input.

#### Scenario: Segment concatenation
- **WHEN** `segment(input)` produces segments s1..sN
- **THEN** concatenating s1..sN SHALL equal the original input

### Requirement: Layout write_layout does not panic
`write_layout()` SHALL NOT panic on arbitrary Layout trees and terminal widths.

#### Scenario: Arbitrary layout and width
- **WHEN** `write_layout` is called with a generated Layout and arbitrary terminal width
- **THEN** it SHALL complete without panicking

### Requirement: Transform functions are idempotent
`truncate_matched_anywhere` and `dim_unevaluated` SHALL be idempotent.

#### Scenario: truncate_matched_anywhere idempotency
- **WHEN** applying `truncate_matched_anywhere` twice
- **THEN** the result SHALL equal applying it once

#### Scenario: dim_unevaluated idempotency
- **WHEN** applying `dim_unevaluated` twice
- **THEN** the result SHALL equal applying it once

### Requirement: ContextFacts merge is commutative
`ContextFacts::merge` SHALL be commutative: `a.merge(b) == b.merge(a)`.

#### Scenario: Merge commutativity
- **WHEN** merging two arbitrary ContextFacts in both orders
- **THEN** the results SHALL be equal

### Requirement: Resolution completeness
After successful `validate_and_resolve`, no `Predicate::Named` variants SHALL remain in the resolved config.

#### Scenario: No lingering Named predicates
- **WHEN** `validate_and_resolve` returns Ok
- **THEN** walking all predicates in the result SHALL find zero `Named` variants
